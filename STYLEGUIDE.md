# Style Guide

## Visual Direction
- Mood: editorial, calm, refined, product-minded.
- Personality: clean portfolio with soft craft details, not corporate-flat and not neon-tech.
- Layout: airy spacing, centered storytelling moments, soft panels, restrained decoration.

## Typography
- Display: `Cormorant Garamond`
  Use for hero names, major headings, and standout statements.
- Body: `Manrope`
  Use for paragraphs, navigation, buttons, and UI text.
- Mono: `IBM Plex Mono`
  Use for labels, metadata, timestamps, and technical accents.

## Rules
- Use serif display type only for key headings.
- Keep body copy neutral and readable.
- Use mono only for small eyebrow and metadata text.
- Prefer warm paper backgrounds over pure white.
- Use champagne, bronze, ivory, and charcoal accents for a more elegant and premium feel.
